# NovaSync — Mobile App Showcase

Modern responsive landing page for an AI-powered productivity mobile app.

## Included

- Semantic HTML5 and Tailwind CSS via CDN
- Inter typography
- Glassmorphism dark UI with cyan accents
- Responsive hero with iOS and Android download CTAs
- Floating mobile app mockups
- Feature bento grid
- Three-screen showcase
- Ratings, testimonials, FAQ, final CTA, and footer
- No backend lock-in; buttons are ready to connect to store URLs, APIs, or analytics

## Run locally

```bash
python3 -m http.server 4174
```

Open `http://localhost:4174`.

## Customize

Search and replace `NovaSync`, update copy, connect the download anchors to real App Store and Google Play URLs, and replace the mockup content with real screenshots when available.
